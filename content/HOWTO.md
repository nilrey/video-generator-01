# Как сделать ролик по своему промпту

## Шаг 1. Сформулируй запрос

Опиши тему, аудиторию, длину, стиль. Примеры хороших запросов:

- «Хочу ролик про то, как работает рекомендательная система YouTube. 5 типов моделей, для широкой аудитории.»
- «Ролик про кредитный скоринг для банковских сотрудников. 4 модели: нейросеть, дерево решений, логистическая регрессия, ансамбль.»
- «Короткое видео про то, как свёрточные сети распознают лица. Только CNN и MLP, для студентов.»
- «Ролик про историю нейросетей: перцептрон, обратное распространение, свёртки, трансформеры. 4 этапа.»
- «Англоязычный ролик про GAN и диффузию. 4 сцены, tech-стиль.»

Что указать, если хочешь точнее:
- число моделей/типов,
- аудиторию (студенты / бизнес / широкая),
- язык (русский / английский),
- стиль палитры (тёплая / холодная / tech),
- особые требования к иллюстрациям (например, «MLP с 4 входами и 2 выходами»).

## Шаг 2. Скопируй промпт в LLM

Открой content/PROMPT.md, скопируй весь файл целиком в ChatGPT/Claude,
добавь в конце свой запрос из шага 1.

Пример сообщения:

> [весь текст PROMPT.md]
>
> ---
>
> Мой запрос: «Хочу ролик про кредитный скоринг для банковских сотрудников.
> 5 моделей. Русский язык. Холодная палитра (синий/бирюзовый).»

## Шаг 3. Скопируй JSON в файл

LLM ответит чистым JSON. Скопируй его в content/scenes.json (замени всё
содержимое). Если LLM добавил обёртку из трёх обратных кавычек — убери её,
оставь только внутренности.

## Шаг 4. Проверь перед рендером

    python -c "from scenes_loader import load_scenes; d = load_scenes('content/scenes.json'); print('OK, сцен:', len(d['scenes']), 'типов:', d['meta']['types_count'])"

Если выведет OK, сцен: 7 типов: 5 — всё хорошо.
Если ошибка — она укажет, что именно не так (поле, ключ, размер).

## Шаг 5. Запусти рендер

    python video_generator.py

Готовый mp4 — в output/<timestamp>/<output_name>.

## Если что-то не так

- LLM выдал JSON с ошибкой — скопируй ошибку из шага 4 обратно в чат с LLM,
  попроси исправить. Обычно хватает одной итерации.
- ill_params не подошли — поправь руками в content/scenes.json.
- Хочешь другой стиль — правь content/presets/default_style.json,
  не трогая scenes.json.
- Хочешь другой ролик — вернись к шагу 1. Старый scenes.json сохрани как
  content/scenes.<тема>.json.

## Что делать, если LLM упорно ошибается

Скажи ему: «Твой JSON не проходит валидацию: <текст ошибки>. Исправь только
это поле, остальное не трогай.» Обычно помогает.
